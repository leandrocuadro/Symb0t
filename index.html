Búsqueda estándar

    Plantilla para armar la base de símbolos de un cliente, con las columnas simbolo y codigo. Los valores repetidos en cada columna se marcan en rojo, para corregirlos antes de subir el archivo a la base de datos con el nombre NRO_CLIENTE.parquet (por ejemplo 22434.parquet).

    Búsqueda avanzada

      Descargá esta plantilla y completá la columna SIMBOLO con los símbolos del cliente, uno por fila, desde la fila 2. Después subila con "Cargar Excel". El sistema devuelve el código y el detalle de cada símbolo. Los que no existen en la base del cliente salen con código 0. Ingresá un cliente válido para habilitar la carga.
